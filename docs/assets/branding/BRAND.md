# Singular — identité visuelle v2

## Palette

- Indigo profond : `#0A1BFF`
- Bleu électrique : `#2D6BFF`
- Bleu clair : `#00A7FF`
- Cyan numérique : `#00E0D1`
- Navy : `#0B1124`
- Blanc : `#FFFFFF`

Dégradé principal : `#0A1BFF → #2D6BFF → #00A7FF → #00E0D1`.

## Fichiers

- `singular-logo.svg` : logo horizontal principal, recommandé pour le README et la documentation.
- `singular-logo-stacked.svg` : version verticale.
- `singular-icon.svg` : symbole seul, recommandé pour favicon, app icon et espaces compacts.

Les mêmes ressources principales sont copiées dans `src/singular/dashboard/static/` pour leur utilisation par le dashboard web.
