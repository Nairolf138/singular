# Historique des versions

## [0.1.0]

Première version destinée aux parcours CLI décrits comme `stable` dans le
[registre canonique](docs/README.md#registre-des-capacités-stable). Consultez
les [notes de version](docs/releases/v0.1.0.md) pour les prérequis et les
fonctionnalités exclues du périmètre stable.

La version déclarée dans `pyproject.toml` ne constitue pas à elle seule une
release : seul le tag `v0.1.0` et ses distributions attachées font foi.
